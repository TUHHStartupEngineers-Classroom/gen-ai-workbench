# Send-ready checklist

A report is send-ready when all eight items are ticked. In the timed run, write your felt estimate and run `bash a04/tools/lap.sh ai stop` only when every item is ticked. Note the ticks in `experiment_log.md` §2.

1. [ ] Every section of the template is filled in.
2. [ ] The status colour is justified by a fact from the sources.
3. [ ] Every number and date matches a source file.
4. [ ] There is no statement without a source.
5. [ ] Unknown items are marked as open (for example "not yet reported"), not guessed.
6. [ ] Decisions needed from management are stated with a date.
7. [ ] Nothing from other projects is in the report.
8. [ ] The report fits on one page and is readable without the source files.
