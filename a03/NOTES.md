# A3 session log

Short notes that carry your work from one agent session to the next. At the end of a session, ask the agent to append an entry here; at the start of the next one, begin with: "Read `a03/NOTES.md` and `a03/run_log.md` first."

Keep each entry to a few lines. Newest entry at the bottom.

## Entry format

```text
## YYYY-MM-DD · session N
- Tried:
- Best version so far (run name, mean field accuracy):
- Open question / next idea:
```
